# Roadmap

## 0.3 preview implemented

- GPU WebGL scenes, native wallpaper hosting and GPU studio previews.
- Flow moods, private focus timer, photo palette extraction and signature seeds.
- 16 scenes, matching desktop clock and native Windows appearance settings.
- Portable descriptive recipe sharing, favorites and creator image packs.
- Saved session resume, explicit stop/restore, renderer ownership and one app instance.

## Compatibility next

- Multiple physical monitors, mixed DPI, HDR, hot-plug and sleep/resume matrix.
- Wider GPU/build coverage, sustained frame pacing and memory budgets.
- Explicit startup opt-in, code signing and update delivery.
- Better preservation of Spotlight/slideshow scheduling.

## Creative tools next

- Licensed high-resolution photo collections, layered depth assets and local video playback.
- Audio-reactive scenes, per-monitor selection and additional widgets.
- Moderated hosted discovery and creator pages after operating rules and infrastructure are defined.

GitHub publication is pending. Discord is configured; donations remain optional and unconfigured.
